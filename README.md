# 📂 Highlight Projects

## 🔹 ShopFlow — Java 21 / Spring Boot Backend

Backend system focused on applying modern Java and Spring Boot concepts to a modular e-commerce and reservation domain.

### Technologies

- Java 21
- Spring Boot 3
- Spring MVC
- Spring Data JPA / Hibernate
- PostgreSQL
- Redis
- RabbitMQ
- Docker Compose
- Maven

### Architecture

The application is organized by business domains:

- Product
- Inventory
- Cart
- Order
- Reservation
- Shared infrastructure

Each domain follows a clear separation between:

`Controller → Service → Repository`

with DTOs and domain entities responsible for their respective concerns.

### Engineering Concepts

- Domain-oriented modularization
- Object-Oriented Programming
- SOLID principles
- Dependency Injection
- Transaction management
- Centralized exception handling
- Domain state transitions
- REST API design
- DTO-based contracts

### Backend Features

- Product management
- Inventory management
- Shopping cart
- Checkout and order creation
- Stock reservation
- Automatic reservation expiration
- Stock release after expiration
- Redis caching with TTL
- Scheduled background processing
- Spring Application Events
- Application health and metrics with Actuator

### Infrastructure

Docker Compose is used to provide isolated development services:

- PostgreSQL
- Redis
- RabbitMQ

The architecture is also structured to support future asynchronous communication through message brokers.

Repository:

https://github.com/Matheus9557/shopflow
