# 🚀 Projetos em Destaque

## 🛒 ShopFlow — API Back-end para E-commerce

Sistema back-end desenvolvido com Java 21 e Spring Boot para gerenciamento de produtos, estoque, carrinho, pedidos e reservas.

### Principais características

* Java 21 e Spring Boot 3
* Spring MVC, Spring Data JPA e Hibernate
* PostgreSQL
* Arquitetura modular orientada ao domínio
* APIs REST
* Regras de negócio e transações
* Gerenciamento de estoque e reservas
* Redis utilizando Cache-Aside e TTL
* Processamento agendado com Spring Scheduling
* Spring Application Events
* Spring Boot Actuator
* Docker Compose
* PostgreSQL, Redis e RabbitMQ em containers

### Arquitetura

A aplicação utiliza separação de responsabilidades entre:

`Controller → Service → Repository`

com uso de DTOs, entidades de domínio, Dependency Injection e princípios SOLID.

🔗 **Repositório:**
https://github.com/Matheus9557/shopflow

## 🦷 OralSync — Plataforma Full Stack para Gestão Odontológica

Plataforma Full Stack desenvolvida para acompanhamento odontológico e comunicação entre profissionais e pacientes.

### Front-end

* React
* TypeScript
* Vite
* Tailwind CSS
* Componentização e interfaces responsivas
* Integração com APIs REST
* Dashboard e visualização de dados

### Back-end

* Node.js
* TypeScript
* Express
* PostgreSQL
* Prisma ORM
* JWT
* Socket.IO
* Jest
* Supertest
* Swagger/OpenAPI

### Principais funcionalidades

* Autenticação e autorização baseada em perfis
* Gerenciamento de pacientes e profissionais
* Acompanhamento de avaliações odontológicas
* Monitoramento diário de dor
* Upload e gerenciamento de imagens clínicas
* Acompanhamento da evolução do paciente
* Comunicação em tempo real
* Sistema de mensagens
* Sistema de notificações
* Controle de notificações não lidas
* Integração entre front-end e back-end por APIs REST

### Infraestrutura

* Backend hospedado no Render
* PostgreSQL hospedado no Neon
* Frontend hospedado na Vercel
* Cloudinary para armazenamento de arquivos e imagens
* Docker para padronização do ambiente de desenvolvimento
